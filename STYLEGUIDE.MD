# Style Guide

## Colour Palette

| Colour Name | Hex Value | Purpose |
|---|---|---|
| Movie Red | #cc0000 | Used for the MovieFlix logo and hover effects |
| Navigation Blue | #1a1a8f | Used for navigation menu links |
| Light Gray | #f4f4f4 | Main background colour of the application |
| White | #ffffff | Used for the navbar and footer background |
| Dark Gray | #333333 | Used for normal text throughout the app |

---

## Fonts

The application mainly uses:

- Arial
- Helvetica
- sans-serif

These fonts were chosen because they are simple, modern, and easy to read.

---

## Font Sizes

| Text Type | Size | Description |
|---|---|---|
| Logo Text | 48px | Main MovieFlix logo/title |
| Main Heading | 56px | Welcome heading on the homepage |
| Body Text | 24px | Main content and descriptions |
| Navigation Text | 18px | Navigation menu items |
| Footer Text | 16px | Group member names and footer text |

---

## General Style Rules

- The application uses a clean and simple movie streaming style.
- Light background colours are used to improve readability.
- Red is used as the main branding colour for MovieFlix.
- Navigation links use blue to stand out clearly.
- Spacing between sections should remain clean and organized.
- All pages should use consistent fonts, colours, and sizing.
- The design should remain simple and user-friendly across the application.
